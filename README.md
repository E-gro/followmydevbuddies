# Follow My Dev Buddies • Comunidade Amigos do Mag

Portal oficial de networking e conexões rápidas criado para a comunidade **Amigos do Mag**, permitindo que todos os membros cadastrem suas redes sociais em um único lugar sem transformar o grupo de WhatsApp em um scroll infinito de links.

## ✨ Funcionalidades

- **Diretório da Comunidade Amigos do Mag**: Cards responsivos com destaque para o Host (**Mag**) e membros da comunidade.
- **Modo Fila Rápida (Speed-Run)**: Siga todos os devs pendentes em sequência com 1 clique por perfil (*Abrir Perfil & Marcar Seguido → Próximo*).
- **1-Click: Abrir + Marcar Automaticamente**: Ao clicar para abrir qualquer rede social de um membro, o portal já marca automaticamente aquela rede como seguida na sua barra de progresso.
- **Modo Deep-Link Mobile (`instagram://`, `twitter://`, `linkedin://`)**: Abre o perfil direto dentro do aplicativo nativo logado no celular.
- **1-Click Follow Real no GitHub**: Integração com a API oficial do GitHub (`PUT /user/following/:username`) para seguir individualmente ou todos os GitHubs da comunidade de uma só vez.
- **Auto-Preencher com GitHub no Cadastro**: Basta digitar seu username do GitHub para puxar foto, nome, bio, site e X/Twitter automaticamente.

## 🚀 Como rodar localmente

```bash
npm install
npm run dev
```
